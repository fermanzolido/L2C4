## 2026-06-20 - [Optimized core object collection paths]
**Learning:** Replacing `LinkedList` with `ArrayList` in hot paths like world visibility and NPC collection significantly reduces allocation overhead and improves CPU cache efficiency. Pre-allocating `ArrayList` capacity based on expected size (e.g., surrounding objects or total NPCs) further minimizes internal array growth and GC pressure. When refactoring these core collections, it's critical to update dependent `instanceof` checks (e.g., in `Skill.getTargetList`) to support the new types while maintaining backward compatibility with legacy script-based handlers.
**Action:** Always prefer `ArrayList` for internal object collection and gathering. When refactoring common utility methods that return lists, perform a global search for `instanceof LinkedList` to identify and update logic that relies on specific list implementations.
