## 2026-05-28 - ArrayList vs LinkedList for Entity Collections
**Learning:** In high-frequency game loop paths (like World visibility checks or NPC/Effect lookups), `ArrayList` is significantly faster than `LinkedList` (~39% faster in benchmarks) due to better cache locality and reduced object allocation (no `Node` overhead). Pre-allocating capacity when the source size is known (and O(1) to retrieve) provides additional wins. However, calling `.size()` on a `ConcurrentLinkedQueue` is O(n), so it should be avoided when initializing an `ArrayList` from it.
**Action:** Always prefer `ArrayList` for transient entity collections. Pre-allocate capacity if the source is a `Collection` or `Array` with O(1) size retrieval. For `ConcurrentLinkedQueue`, use default `ArrayList` constructor or a conservative estimate.
